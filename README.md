# Among Blocks 👾🧱

A fun, kid-friendly fan **mashup of Among Us and Roblox** — built as a single static page with
original SVG artwork (no copyrighted game assets).

## Features
- 🎨 **Make Your Crewmate** — pick a colour, roll a silly name
- 🔎 **Find the Impostor** — a "spot the odd one" game that gets harder each level
- 📋 **Do Your Tasks** — click tasks to fill the crew's task bar
- 🧱 **The Blocky Obby** — a silly step-by-step obstacle course
- 🚨 **Emergency Meeting** — random silly messages + screen shake
- 🎉 Confetti, bobbing animations and lots of colour

## Run locally
Open `index.html`, or:

```bash
python3 -m http.server 8000
```

Just for fun — not an official game. All art is drawn from simple shapes.
